# 🎂 Java Age Calculator

## 📌 About the Project
The **Age Calculator** is a simple Java-based application that calculates a person's age using their date of birth. It takes the birth date as input, compares it with the current date, and displays the accurate age in years, months, and days.

This project demonstrates basic Java programming concepts, date handling, and user input.

## ✨ Features
- Accepts the user's date of birth.
- Calculates age based on the current date.
- Displays age in years, months, and days.
- Uses Java's built-in Date and Time API.
- Simple and beginner-friendly implementation.

## 🛠️ Technologies Used
- **Language:** Java
- **Concepts:** User Input, Date Handling, Conditional Logic
- **API:** `java.time` package

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/age-calculator.git
   ```

2. Open the project in VS Code or any Java IDE.

3. Compile the Java file:
   ```bash
   javac AgeCalculator.java
   ```

4. Run the program:
   ```bash
   java AgeCalculator
   ```

## 💻 Sample Output

```text
Enter your date of birth (YYYY-MM-DD):
2006-06-29

Your Age:
20 Years, 4 Months, 22 Days
```

*Note: The output changes depending on the current date and the entered date of birth.*
